# 醒图 2.0｜原生画布编辑器 UI 视觉与图标规范

版本：1.0 ｜ 日期：2026-11-28 ｜ 适用范围：新版 XingtuEditorV2Screen 与全部二级面板

## 1. 设计方向

- 以当前 APP 的 MaterialTheme.colorScheme 为颜色唯一来源，不另造固定品牌色。
- 画布是视觉焦点，工具区轻量、低对比；不增加大面积纹理背景、装饰图案或多层嵌套卡片。
- 沿用旧醒图页已有的 glyph 图标风格和标签组合，不使用上一版新增的自绘矢量图标。
- 每个可点击功能必须有“语义图标 + 简短中文标签”；纯图标按钮只用于返回、撤销、重做、更多、关闭、确认等通用动作，并保证可访问点击区域。
- 同一功能在一级工具栏、对象快捷栏、二级分类和图层列表中复用同一图标语义。

## 3. 图标语义

直接复用现有醒图页的 editorToolGlyph 图标语义与 EditorTool 视觉规范，不另造一套 Canvas 自绘图标。图标尺寸、字形、颜色和标签层级与旧醒图页一致；可点击功能仍保留图标与简短中文标签。

| 功能 | 图标语义 |
|---|---|
| 文字 / 字体 / 编辑 | 字符排版、字形、铅笔 |
| 图片 / 替换 / 裁剪 | 图片框、双向替换箭头、裁剪角 |
| 图层 / 组件 | 堆叠层片、容器/形状 |
| 样式 / 滤镜 / 调色 | 样式轮廓、滤镜节点、调节滑杆 |
| 排版 / 对齐 / 分布 | 网格、对齐线、均匀分布线 |
| 透明度 / 阴影 / 边框 / 圆角 | 半透明圆、偏移阴影、矩形边框、圆角矩形 |
| 变换 / 旋转 / 镜像 | 变换框、旋转箭头、翻转箭头 |
| 复制 / 删除 / 锁定 | 双层矩形、垃圾桶、锁体 |
| 返回 / 撤销 / 重做 / 更多 | 左向折线、回转箭头、反向回转箭头、三点 |
| 关闭 / 确认 | 交叉线、勾选线 |

## 4. 排版规则

1. 一级入口始终等宽居中，不随标签长度改变图标中心线。
2. 对象快捷栏只展示当前对象可用工具，横向滚动时按钮高度和内边距不变。
3. 二级面板分类行不换行，横向滚动；当前分类用主题色强调，其他分类保持中性色。
4. 参数项按“名称与数值同一行、滑块下一行”排列；同一面板内垂直间距一致。
5. 色板采用统一尺寸与间距；当前选中色板使用主题色描边，不添加阴影。
6. 不使用过多卡片容器；通过 8/12/16dp 间距和轻分隔线分组。
7. 小屏宽度下，分类/工具栏横向滚动，不缩小图标至不可辨识。
8. 所有交互控件需有明确选中、禁用、按下状态；禁用图标降低透明度，选中态使用主题色。

## 5. 文字尺寸模型

- 字号（fontSizeSp）只控制实际字形字号。
- 文本框宽高（boxWidth / boxHeight）只控制文字内容布局与换行/可视范围。
- 对象外框宽高（transform.width / transform.height）只控制画布选择框与对象几何边界。
- 对象整体缩放（transform.scaleX / scaleY）控制对象整体比例；reducer 不得把文本框宽高自动覆写成对象外框宽高。
- 文字面板“排版”只编辑文本框宽高、行距、字距、对齐；“变换”单独编辑对象位置、外框宽高、旋转、整体缩放。
- 新建文字时显式初始化文本框宽高；旧文档读取时保留原有值，禁止无提示重置用户数据。

- 视觉基准直接取自 `ArticleEditorScreen.kt`：底部主工具栏 `#181818`、50dp 高；面板背景 `#181818`；面板内部工具块沿用 `EditorTool` 的 54dp 最小尺寸、10dp 圆角、选中主题色浅底与细边框。
