# 醒图改版阶段 C：新版二级面板统一规范与首轮实现

> 实施分支：`ui/xingtu-redesign-preserve-legacy`  
> 目标页面：`ArticleEditorRedesignedScreen.kt`  
> 本阶段仅作用于新版页面；旧版 `ArticleEditorScreen.kt` 保留原样。

## 1. 视觉延续原则

- 沿用当前编辑器深色工具面板、主题强调色、圆角按钮和紧凑工具坞的既有视觉语言。
- 保留面板工作面 `#181818`、工具项深色底 `#222222`、主题强调色和页面原有底色。
- 不重做整页底纹，不更换主色，不改变中央文章画布、文章 HTML 样式或数据结构。
- 统一的是面板内部信息层级、留白、按钮间距、标题和顶部操作顺序，而不是把每个面板改成同一种内容。

## 2. 二级面板统一框架

所有一级入口唤起的二级面板遵循同一框架：

1. 面板覆盖底部一级导航所在位置，打开时一级导航隐藏；面板内部不再重复一级导航。
2. 顶部操作行固定 48dp：左侧关闭，中间为当前面板标题或二级分类，右侧确认/完成。
3. 顶部操作行下增加 1dp 低对比度分隔线，不增加新的卡片底纹。
4. 面板初始高度 200dp，最低 200dp，最高 400dp。
5. 顶部拖动滑块默认不显示；检测到向上拖动后显示细短滑块。
6. 面板打开时隐藏 Android 输入法，但保留画布当前对象和文字 Range。
7. 面板内容区独立滚动，滑块手势不能抢占按钮、滑块、横向滚动和文字长按选择。
8. TEXT2 文字属性工作区继续使用自己的内部滚动区域，避免双层纵向滚动竞争。

## 3. 首轮 UI 统一改动

新增 `native-overlay/apply_redesigned_xingtu_stage_c.py`，在新版页面生成后执行：

- 将顶部操作统一为左侧关闭图标、右侧完成图标；两个操作均只关闭当前面板，不擅自回滚实时预览。
- 在面板顶部和内容区之间增加低对比度分隔线。
- 统一面板内容左右边距为 14dp、上下边距为 8dp。
- 面板内 FlowRow 工具组统一 6dp 横向与纵向间距；只修改 FlowRow，不改 Row 的参数。
- 统一二级面板小节标题为 11sp、中等字重、浅灰文字和一致的下边距。
- 保留每个 EditorPanel 分支、工具项、点击回调和现有滚动状态。
- 修复一级导航过滤条件：将原本被模板子分类过滤掉的 IMAGE、LAYOUT、CARD、COMPONENT、SVG 重新作为直接一级入口显示；模板子导航仍保留同名素材分类，语义分别为直接编辑工具与模板素材分类。

## 4. 面板内容分类基线

| 面板 | 内容组织原则 |
|---|---|
| 文字 | 常用文字格式、段落结构、快捷格式、查找替换分组；保留原有所有操作 |
| 图片 | 导入/图片组、选中图片属性、本地素材库分组；裁切与调色继续走专业子面板 |
| 文字属性 | 字体、样式、排版三个主标签；样式内含文本、描边、阴影、发光、背景 |
| 标题 | 按标题视觉样式分类，不改插入 HTML |
| 布局 | 预设布局、自定义分栏、图文组合分组 |
| 卡片 | 按内容卡片与信息组件分类，保留原始模板 |
| 组件 | 按组件类型与组合组件分类 |
| SVG | SVG 素材和交互组件分组 |
| 图文收藏 | 收藏、分类、搜索和复用分组 |
| 图层 | 图层选择、显隐、锁定、层级和对象操作分组 |
| 画布 | 页面/画布参数与浮层操作分开 |
| 文档 | 文章管理、元信息、导入导出、版本和检查功能分组 |
| 模板 | 整篇模板与局部模板分开；局部模板按标题、卡片、图片、布局、SVG、组件分类 |

## 5. 仍需后续完成的事项

- 各面板内部功能项按上述分组进一步整理；首轮先统一外框，不删除或隐藏未完成归类的工具。
- 对重复入口建立“主入口 + 快捷入口”关系，保留两者，不造成重复功能状态冲突。
- 所有专业编辑窗口、表单窗口和确认窗口在阶段 D 统一尺寸、标题、按钮、键盘避让和关闭语义。
- 返回栈和输入法/选区状态迁移在阶段 E 继续完善；阶段 C 不把面板关闭误当作清除对象选区。
- 需以 APK 构建、设备操作和画布实时同步回归作为最终验收，不把脚本执行成功视为 UI 验收通过。
