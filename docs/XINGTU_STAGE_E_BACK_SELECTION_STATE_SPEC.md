# 醒图改版阶段 E：返回层级、输入法与选区状态机

## 目标

将系统返回键、手势返回和页面左上角返回统一交给新版编辑器的 `handleEditorBack()`。每次返回只退出当前最上层交互，不跨层清空状态。

## 返回顺序

1. Android 输入法先按系统行为收起；IME 可见期间不抢夺系统键盘返回。
2. 若文字编辑期间键盘已收起，恢复 WebView 中保存的文字 Range，将编辑状态退回文字选中状态。
3. 再次返回才清除文字选区。
4. 清除图片、组件、多选等对象选区。
5. 关闭悬浮菜单、插入菜单、更多工具、模板子导航等子层。
6. 关闭专业窗口、预览窗口、确认窗、文章列表和二级面板。
7. 最后保存文档并离开编辑器。

## 本轮实现

- 新增 IME 可见状态观察，只有文字 Range / 文字块 / 光标选区处于活动状态时，键盘弹出才标记文字编辑会话。
- 二级面板打开时继续隐藏输入法，不清除当前 WebView Range。
- 浮动菜单优先于父级二级面板关闭。
- 图片素材选择窗口单独关闭，不顺带清除画布选区。
- 文字编辑结束后调用 `restoreSelection()`，重新启用文字选区预览，并保留选中态；下一次返回才清除选区。
- 系统返回和顶部返回继续共用同一个协调器。
- 保留所有保存回调、文章状态、导入导出、模板、图片、裁切、调色、布局、组件和历史版本逻辑。

## 保护边界

- 仅修改构建生成的 `ArticleEditorRedesignedScreen.kt`。
- 不修改旧版 `ArticleEditorScreen.kt`。
- 不改文章 HTML、WebView 内容、数据模型和保存策略。
- 不把所有返回动作合并成一次性关闭。
- 不构建 APK、不触发 APK 构建。
- 编译与真机返回键验收留待后续专门验证。
