# 醒图改版阶段 E：返回层级、输入法与选区状态机

## 目标

将系统返回键、手势返回和页面左上角返回统一交给新版编辑器的 `handleEditorBack()`。每次返回只退出当前最上层交互，不跨层清空状态。

## 返回顺序

1. Android 输入法先按系统行为收起；IME 可见期间禁用编辑器的系统 BackHandler，不抢夺系统键盘返回。
2. 顶部返回按钮在 IME 可见时只隐藏输入法，不离开页面。
3. 输入法收起后，若文字编辑会话仍活动，第一次返回恢复 WebView 中保存的文字 Range，将编辑状态退回文字选中状态。
4. 再次返回才清除文字选区。
5. 清除图片、组件、多选等对象选区。
6. 关闭最上层浮动子菜单，再关闭删除确认、预览、素材窗口、专业窗口、文章列表和二级面板等父层。
7. 最后保存文档并离开编辑器。

## 本轮实现

- 新增 IME 可见状态观察；仅当文字 Range、文字块或光标选区活动时，IME 弹出才标记文字编辑会话。
- 显式补齐 Compose Foundation Layout 的 `WindowInsets` / `ime` 导入（当源文件没有通配导入时）。
- 二级面板打开时继续隐藏输入法，不清除当前 WebView Range。
- 浮动菜单被提升到返回协调器第一层，确保先于父级确认窗或面板关闭。
- 图片素材选择窗口沿用生成器中的单一独立关闭分支；补丁会验证该分支恰好出现一次，避免重复注入。
- 文字编辑结束后调用 `restoreSelection()`，重新启用文字选区预览，并保留选中态；下一次返回才清除选区。
- 系统返回和顶部返回继续共用同一个协调器。
- 保留所有保存回调、文章状态、导入导出、模板、图片、裁切、调色、布局、组件和历史版本逻辑。

## 自动静态检查

`native-overlay/apply_redesigned_xingtu_stage_e.py` 会检查：

- IME observer、IME first、系统 BackHandler 与顶部 Back 共用 coordinator。
- 浮动菜单、所有父层临时窗口、文字编辑恢复、对象选区清理和最终保存离开的严格顺序。
- 图片素材选择窗口关闭分支恰好一处。
- 最终保存/离开是唯一终止分支。

## 保护边界

- 仅修改构建生成的 `ArticleEditorRedesignedScreen.kt`。
- 不修改旧版 `ArticleEditorScreen.kt`。
- 不改文章 HTML、WebView 内容、数据模型和保存策略。
- 不把所有返回动作合并成一次性关闭。
- 不构建 APK、不触发 APK 构建。
- 编译与真机返回键验收仍需后续专门验证；静态检查通过不代表运行时行为已验收。
