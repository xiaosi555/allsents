# 拾万句线性图标系统规范

## 视觉基准

以用户于 2026-11-28 提供的「拾万句·线性图标全集」截图为唯一视觉基准。

- 画布：24 × 24。
- 线宽：1.5。
- 线帽：round。
- 线连接：round。
- 安全留白：图形主体距画布边缘约 3。
- 图形：仅使用直线、圆弧、矩形及其组合。
- 外观：单色描边；不使用渐变、实心填充、阴影、表情符号或文字字符代替图标。
- 颜色：继承对应文字颜色；选中态使用主题色，不改变线宽、尺寸和图形。
- 尺寸：同一控件层级统一图标显示尺寸；禁止通过单独放大某个图标弥补图形比例问题。
- 语义：图标必须准确表达相邻功能文字，不能只因外形相似而复用错误语义。

## 全项目接入要求

1. 所有实际显示的功能图标必须有稳定 key，并从统一图标库调用。
2. 所有页面、导航、底部工具栏、二级面板、弹窗、素材中心、图层面板、设置页逐项盘点。
3. 禁止使用 Unicode 字符、Emoji、字母或标点作为功能图标；如「T」「文」「◉」「▧」「↻」「⌫」等必须替换为图标资源。
4. 禁止页面自行声明同义图标或私自引入另一套图标体系。
5. 图标库中没有的语义，先补充统一资源和 key，再在页面调用。
6. 同一语义必须复用同一个 key；不同语义不能为了省图标而复用同一个 key。
7. 图标库页面提供分类、搜索、预览与替换能力；替换 key 对应资源后，所有调用位置同步生效。
8. 迁移范围包括主页、排版、秀米、醒图、醒图 2.0、我的、图标库，以及它们的所有子面板和弹窗。
9. 迁移完成后执行静态扫描：检查直接 Material Icons 引用、字符图标、Emoji 图标、无 key 图标、缺少中文语义说明的图标。
10. 构建通过后仍需检查关键页面截图，确认实际渲染风格一致；不能把脚本执行成功等同于视觉验收通过。
