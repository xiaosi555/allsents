> 依据：`native-overlay/app/src/main/java/com/shiwanju/app/ui/ArticleEditorScreen.kt`（main，盘点基线 blob `c96a1ab6ea43d18af11a2dc9a090fe00c989575b`）、`native-overlay/add_xingtu_v3.py`、`.github/workflows/android.yml` 及醒图 3.0 设计规范。

## 1. 当前实现基线

- 原编辑器：单个 Compose `ArticleEditorScreen`，内部嵌入 WebView 文章编辑内核，通过 JavaScript Bridge 接收对象选择/预览事件。
- 3.0 当前实现：构建脚本复制原编辑器到 `com.shiwanju.app.ui.v3`，改 Composable 名称及标题，注册独立路由；**仍然是旧版 UI/状态逻辑的复制，不是 3.0 重构**。
- 当前页面状态大量保存在 Composable 局部 `remember` 中；文章 ID 在编辑器初始化时直接生成新 ID，文章列表选择时再切换到已有 ID。需在阶段 A 明确入口上下文与新建/打开语义。
- 当前一级枚举共有 13 项：文字、文字2、标题、图片、布局、卡片、组件、SVG、图层、图文收藏、图文模板、文档、画布；模板子导航又复用标题/卡片/图片/布局/SVG/组件。这与 3.0 的 8 类目标不一致。
- 当前二级面板高度状态初始化为 100dp，普通面板打开时设为 180dp，范围限制为 100–400dp；不符合规范的 200–400dp。
- 当前面板顶部有“确定”与“关闭”入口，但尚未发现统一的初始快照、事务提交/回滚机制；目前关闭主要是隐藏面板，不能据此认定具备取消恢复。
- 当前工具图标由 `editorToolGlyph(label)` 按中文标签匹配字符，再用 Text 绘制；不符合统一 SVG/vector 图标库规范。
- 当前代码已包含自动保存、文章列表/版本快照、HTML/Markdown/文章包导入导出、模板库、图片素材库、裁剪、调色入口、图层操作、组件插入等业务，迁移时必须保留。

## 4. 当前明确发现的规范差距

1. **导航分类不符合目标**：旧枚举 13 项，包含“文字2/标题/布局/卡片/SVG/图文收藏/图文模板/画布”等独立项；必须重组为文字、图片、组件、排版、图层、样式、模板、文档 8 类，并把旧入口逐项映射。
2. **二级面板高度不合规**：状态范围为 100–400dp，普通面板默认 180dp；目标为 200–400dp。
3. **缺少可证明的事务语义**：确定/关闭目前没有统一快照与取消回滚机制，不能满足“预览—确定提交—取消恢复”。
4. **图标实现不合规**：`editorToolGlyph` 使用文本匹配返回字符，正式工具图标需改为稳定 icon ID + SVG/vector。
5. **文章上下文风险**：编辑器初始 `articleId` 由 `vm.newId()` 生成；需核实路由/排版入口是否能传入当前文章 ID，文章列表打开流程是否会在进入时误建草稿。
6. **编辑会话状态耦合**：当前大量局部状态与单个 `AppViewModel` 共存；需为 3.0 独立管理面板、选区、草稿、撤销历史，避免和原编辑器串线。
7. **对象类型覆盖不完整**：目前 Bridge 明确回调 block/image/text，SVG、表格、多选等需确认是否有统一身份与属性同步接口。
8. **分类重复入口**：模板子导航包含图片/布局/组件等，与主导航重复；新结构应只保留一个主要归属，快捷入口复用同一实现。
9. **“画布设置”归类需调整**：宽度、留白、对齐、间距归入排版；文章背景/文章级外观按属性作用域归入样式或文档，避免误改整篇。
10. **历史撤销与面板事务未统一**：需要确认 JS undo/redo 与 Compose 面板编辑的历史边界，避免面板取消后仍残留历史。

## 6. 阶段 A/B 实现映射补充（2026-11-29）

### A：文章上下文
- V3 入口通过独立 `xingtu_v3_editor_session/active_article_id` 保存最后打开的文章 ID，不复用原醒图编辑器的局部状态。
- V3 初始化按可选 `initialArticleId` 或上次 V3 文章 ID 恢复文章；未找到有效文章时才创建新 ID。
- 文章打开/新建时更新会话 ID；同一 Composable 宿主切换到另一个有效文章 ID 时，先保存当前文档，再切换目标文档。
- 文章持久化数据继续复用 `AppViewModel` 的 `articles`、`mediaAssets`、`articleRevisions`；选中状态、面板状态和交互状态由独立 V3 Composable 管理。
- 当前排版页的通用 3.0 入口不携带文章 ID；它会恢复上一次 V3 文档。可选 ID 参数为后续明确的文章上下文入口保留。
