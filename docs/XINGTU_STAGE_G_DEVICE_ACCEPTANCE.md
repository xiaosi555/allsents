# 醒图改版阶段 G：真机交互验收矩阵

## 验收边界

本阶段把源码/编译检查与设备运行验收分开记录。阶段 C–F 的补丁和 Kotlin 编译检查通过，不等于触控、IME、WebView 选区或图片处理已经在真机通过。

- 当前不构建 APK，不触发 `assembleDebug`、打包或上传。
- 不修改旧版编辑器的业务逻辑；新版入口与旧版入口必须分别可进入。
- 每项测试必须记录设备型号、Android 版本、屏幕密度/分辨率、应用版本、结果和复现步骤。
- 未在设备上实际执行的项目统一标记为“待真机”，不能标记为通过。
