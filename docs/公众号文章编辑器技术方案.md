# 公众号文章编辑器技术方案

## 1. 目标与边界

在现有「排版 / 我的」原生 Android 应用中新增独立的公众号文章编辑器。编辑器是新增能力，不替换现有排版预览、文案随机读取、素材插入、版式模板及复制逻辑。文章以 HTML 富文本保存，保证复制到微信公众号图文编辑器时尽可能保留样式。

## 2. 现有工程依据

- `000_拾万句.html`：现有 Web 版页面、`appData.files.text` 文案模块结构、分类和本地持久化方式。
- `native-overlay/.../data/Models.kt`：原生数据模型；字段需与 JSON 备份兼容。
- `native-overlay/.../data/Store.kt`：本地 `app_data.json` 持久化、导入导出和数据规范化。
- `native-overlay/.../ui/MyScreens.kt`：我的首页、文案模块列表/宫格/排序/新增/编辑/删除交互。
- `native-overlay/.../ui/LayoutScreen.kt`：排版顶部栏、预览 WebView 和编辑入口。
- `native-overlay/.../ui/AppViewModel.kt`：跨页面共享数据、预览和保存业务。
- `native-overlay/.../ui/PreviewWebView.kt`：现有 WebView 桥接方式，可参考但不复用排版预览的编辑态，避免两套编辑逻辑互相覆盖。

## 3. 入口与页面

### 3.1 排版页入口
- 在顶部「编辑」右侧增加一个仅图标的样式入口（线性图标，不显示文字）。
- 点击后进入独立文章编辑器；返回时回到原排版页，原排版编辑状态和预览数据不丢失。
- 样式入口与现有「编辑 / 完成」状态并存，不改动原编辑按钮行为。

### 3.2 我的 - 样式
- 我的首页增加「样式」入口。
- 样式管理复用文案模块的列表/宫格切换、排序、新增、详情编辑、删除和空状态交互。
- 每条样式模块包含：名称、用户自定义分类、富文本 HTML 内容、更新时间。
- 分类不写死为「朋友圈 / 名句」；用户可自行输入、创建和选择分类。
- 删除样式模块或分类前进行确认；删除分类时若仍有关联样式，必须提示并让用户选择迁移或取消，不能静默丢数据。
- 旧版备份 JSON 缺少新增字段时默认空列表；导入旧备份不丢失原有账号、文案、版式、配图、动图、Emoji、往期数据。

### 3.3 文章编辑器
- 独立全屏页面，顶部提供返回、文章标题、保存状态/保存操作。
- 编辑区采用 WebView `contenteditable` 富文本内核；Compose 原生工具栏负责命令、媒体选择、分类/样式模块选择和页面状态。
- 编辑内容以 HTML 保存，不把 HTML 转成纯文本覆盖。
- 工具栏与编辑区域分离，编辑区域支持滚动、文本选择、光标定位和软键盘。

## 4. 编辑能力清单

### 文本与段落
- 撤销 / 重做、全选、清除格式。
- 粗体、斜体、下划线、删除线、上标、下标。
- 字体大小、字体/字族、文字颜色、背景高亮。
- 段落正文、标题 H1–H4、引用块、代码块、分隔线。
- 左对齐、居中、右对齐、两端对齐。
- 有序列表、无序列表、缩进 / 减少缩进、行距和段前段后间距。

### 内容与媒体
- 插入/编辑/删除超链接。
- 插入图片（本地图片与网络图片）、图片替代文字、宽度/对齐。
- 插入表格、增删行列、单元格编辑。
- 插入音频/视频链接或占位卡片；对公众号不支持直接承载的媒体格式，保留可复制的链接/卡片，不伪称可直接发布。
- 插入日期、特殊符号、Emoji、空行和分隔符。
- 支持粘贴文本与 HTML；对不安全脚本、事件属性和危险 URL 做清理。

### 公众号排版
- 常用公众号正文宽度和移动端预览。
- 文章标题、摘要、作者、正文分区。
- 段落间距、首行缩进、字间距、行高、两侧边距。
- 图片自适应、居中、圆角、说明文字。
- 引用、提示框、编号列表、分割线等常用公众号组件。
- 提供编辑视图与阅读预览切换。
- 复制富文本 HTML 到剪贴板，附带纯文本回退；复制失败时给出明确反馈。

## 5. 自定义样式分类如何进入编辑器

- 「我的 - 样式」管理的分类名称作为编辑器中的功能分类标签。
- 选中分类后展示该分类下已保存的样式模块。
- 点击样式模块将其 HTML 片段插入当前光标位置；若没有有效光标，则追加到正文末尾。
- 新增/修改/删除样式模块后，编辑器分类和内容即时刷新。
- 空分类不隐藏；显示空状态和新增入口，方便先建分类再逐步积累组件。

## 6. 数据模型与兼容

新增根字段：
- `styles: StyleModule[]`
- `articles: ArticleDocument[]`

`StyleModule`：`id`、`name`、`category`、`html`、`updatedAt`。
`ArticleDocument`：`id`、`title`、`html`、`createdAt`、`updatedAt`。

所有新增字段均提供默认值。Gson 反序列化旧备份时缺字段按空列表处理。导入/导出 JSON 保留新增数据。排序仅改变样式模块顺序，不改动 HTML 内容和 ID。

## 7. 安全、稳定与验收

- WebView 禁止任意网页导航和文件访问；仅允许本地编辑文档与必要的图片 URI。
- 图片本地导入时复制到应用私有目录或编码为可持久化资源，不能只保存临时 content URI。
- HTML 清理脚本标签、事件属性和危险协议；不删除合法内联样式、图片、表格、SVG 等公众号常见结构。
- 自动保存草稿；页面返回、进程重建、旋转和软键盘弹出时不得丢失未保存内容。
- 导入旧 JSON、导出新 JSON、再次导入后验证样式模块和文章内容一致。
- 验收必须实际点击每个工具栏功能，检查光标处插入、保存后重进、复制到外部富文本编辑器的结果。
- 构建成功只代表编译通过；还需单独核验 APK artifact，并在可用设备上进行交互安装验证。

## 8. 实施顺序

1. 数据模型、Store 兼容、备份导入导出。
2. 我的 - 样式管理（按文案模块的交互规范）。
3. 独立文章编辑器 WebView 内核和自动保存。
4. 富文本工具栏、媒体插入、公众号组件和预览。
5. 排版页图标入口、分类/样式模块联动。
6. 旧数据兼容测试、编译、APK artifact 检查和设备验收。


## 9. 秀米式工作台与交互规范（新增，作为正式验收范围）

本项目目标是实现适配手机端的「秀米式公众号图文编辑工作台」，覆盖常见图文编辑、模块排版、模板复用、素材管理和发布前检查能力。不是简单复刻 PC 网页布局，也不依赖秀米的私有服务、账号或未公开接口；公众号平台限制的能力必须明确提示。

### 9.1 编辑工作台布局

- 顶栏：深色紧凑操作区，保留返回、文章名称、自动保存状态、撤销、重做、预览；其余低频操作统一收纳到「更多」工具面板。
- 画布区：编辑工作台采用浅灰画布背景，正文呈居中白色纸张，保留手机阅读宽度、页边距与轻量投影；编辑态与阅读预览态共用正文内容，不复制或转换成图片。
- 底部主工具栏：文字、图片、组件、样式、模板五个主入口；每个入口展开对应功能面板，工具按钮采用清晰分组与可滚动布局。
- 「更多」工具面板按快速操作、检查与导入导出、文章管理与版本、链接与模块操作分组；文章列表、立即保存、撤销/重做、预览、全选、富文本/纯文本复制、兼容检查、HTML/Markdown/文章包导入导出、版本记录、文章信息、保存整篇模板、链接插入、多选组合和选中模块操作均须可访问。
- 工具面板：从底部抽屉展开，支持二级分类；打开面板、选择颜色或图片后必须恢复编辑光标/选区。
- 模块选中态：显示轻量边界和模块操作栏，不得出现多层套框或遮挡正文。
- 阅读预览：隐藏编辑控制、选择边框和占位提示，按真实手机文章样式展示。
- 横竖屏、软键盘弹出和小屏设备适配；键盘出现时工具栏可收起，正文自动滚动到光标。


### 9.2 模块操作

所有可视模块支持适用的操作：选中、编辑、复制、删除、上移、下移、拖动排序、保存为我的样式、替换内容、应用样式。拖动必须有明确落点反馈；删除前可撤销。复杂模块内部的文本仍可单独编辑，不得将整块内容变成不可编辑图片。

### 9.3 文字工具箱

- 字符格式：粗体、斜体、下划线、删除线、上标、下标、清除格式、格式刷。
- 字体属性：字号、字族、字重、文字颜色、背景高亮。
- 段落属性：正文、H1-H4、引用、代码、对齐、行高、字间距、首行缩进、段前段后、左右缩进。
- 列表：有序、无序、任务/步骤列表；调整层级、缩进和编号样式。
- 特殊内容：日期、时间、Emoji、特殊符号、空行、分页/分隔线。
- 选择操作：全选、复制、剪切、粘贴、查找替换；选区变化后保留真实 Range。

### 9.4 图片与媒体工具箱

- 相册多选、文件选择、本地图片、网络图片 URL；导入后显示上传/存储状态。
- 图片裁剪、旋转、替换、删除、宽度、对齐、圆角、边框、说明文字、替代文本。
- 图组：双图、三图、网格、横排、纵排；每张图可单独替换和调整。
- 图片库：按导入时间排序、搜索、预览、复用、删除；删除前检查文章引用。
- 媒体：音频/视频以公众号可接受的链接或说明卡片方式呈现；不支持直接发布的媒体必须显示兼容提示。
- 图片资源必须复制到应用私有持久目录并以资源 ID 引用；禁止仅保存短期 content URI 或临时缓存地址。

### 9.5 组件库

首批内置组件按类别提供预览缩略图和可插入 HTML：
- 标题：纯文字标题、编号标题、色块标题、边线标题、上下装饰标题。
- 正文：标准段落、强调段落、首字下沉、重点文字。
- 引用：左边线引用、底色引用、名言卡片、出处卡片。
- 提示：信息提示、注意事项、成功/提醒卡片。
- 列表：圆点、数字、步骤、时间轴。
- 图片：单图、双图、三图、图注、图片卡片。
- 装饰：分割线、留白、符号、角标、标签。
- 卡片：人物介绍、书籍/产品推荐、信息卡、关注引导、作者简介、相关阅读。
- 表格：基础表格、表头表格、简单数据对比。
- 结尾：结束语、版权说明、关注提示、推荐阅读。

组件必须支持插入后继续编辑，不能只提供静态截图。

### 9.6 样式与模板中心

- 模板分为「整篇模板」「局部组件」「我的样式」三类，不能混为一类。
- 分类可由用户创建、重命名、排序、迁移；删除非空分类必须选择迁移或取消。
- 模板支持搜索、收藏、预览、插入、替换当前模块、应用全文、复制、编辑和删除。
- 我的样式支持从当前选中模块保存，也支持多选模块保存为组合组件。
- 插入局部组件只插入光标处；整篇模板需二次确认是否替换当前文章。
- 内置模板以本地资源提供，不依赖外部在线服务；未来可增加可选模板包导入。

### 9.7 文章管理

- 文章列表支持新建、打开、搜索、分类、标签、收藏、复制、重命名、删除、排序。
- 文章状态：草稿、已完成；显示最后编辑时间、字数和图片数量。
- 自动保存草稿，支持最近编辑列表。
- 历史版本：按时间保留关键版本，支持预览和恢复；自动保存对五分钟内的连续编辑合并快照，每篇文章最多保留最近 30 个，避免短暂停顿造成版本快速堆积。
- 支持 HTML 导入/导出、Markdown 导出、JSON 全量备份；导入时先预览并确认，不覆盖同 ID 的现有文章。
- 文章删除与素材删除分离；被其他文章引用的图片不能被静默删除。

### 9.8 公众号阅读与发布前检查

- 阅读预览采用常见公众号手机阅读宽度，检查标题、正文、图片和组件的真实比例。
- 复制提供「富文本 HTML」和「纯文本」两种方式；优先使用剪贴板 HTML，失败时明确提示并提供回退。
- HTML 导出保留必要内联样式；清理脚本、事件属性、危险 URL 和不安全 iframe。
- 兼容检查提示外链图片、超宽表格、外部字体、复杂 CSS、媒体占位、空段落和失效链接。
- 对平台限制仅给出兼容提示，不承诺一键发布、自动上传公众号图片或绕过公众号接口限制。

## 10. 数据结构升级建议

在现有字段基础上向后兼容扩展：

- ArticleDocument：增加 subtitle、summary、author、coverAssetId、categoryId、tags、status、blocks、wordCount、version、lastOpenedAt。
- ArticleBlock：id、type、html、attributes、order、assetIds；允许保留原始 HTML 块，避免导入内容被强制转换丢失。
- StyleModule：增加 type（整篇模板/局部组件/组合组件）、thumbnail、tags、categoryId、origin（official/user）。StyleCategory：独立 ID、名称、排序和创建时间；旧版仅保存分类名称的备份在加载时按名称生成稳定分类 ID，并回填 StyleModule.categoryId，保证旧数据兼容。
- StyleCategory：独立分类 ID、名称、排序和创建时间；避免只用分类名称作为关联键，重命名时不破坏关系。
- MediaAsset：资源 ID、文件名、MIME、相对路径、宽高、大小、创建时间、引用计数。
- ArticleRevision：文章 ID、版本号、标题、HTML/模块快照、创建时间和变更说明。

旧版 JSON 不包含这些字段时统一使用默认值；新版本导出仍保留旧字段。迁移必须幂等，不能每次启动重复插入默认样式。模块数据和 HTML 需通过单一序列化层同步，HTML 是最终渲染/复制产物，模块数据是编辑操作模型。

## 11. 编辑内核的强制技术约束

- 建立独立的 Editor WebView，不复用排版页预览 WebView 的编辑状态。
- 编辑内核封装为独立 JS bridge：命令执行、光标/选区快照、恢复选区、模块插入、模块选择、HTML 读取、预览切换、撤销/重做、内容变更事件。
- 所有原生弹窗/底部面板打开前保存 Range，关闭后恢复 Range；若 Range 已失效，插入到正文末尾并提示，不允许无声丢内容。
- 自动保存使用 750ms 防抖并在返回、切换文章时提交；对比正文及文章元信息，内容未变化时跳过重复写盘。Android UI 隐藏时通过 ComponentCallbacks2 触发一次 WebView 正文读取和保存。历史快照对连续编辑按五分钟窗口合并，保留窗口开始前的版本，每篇文章最多保留最近 30 个；WebView 撤销/重做历史限制为最多 40 份且总字符预算约 8 MiB（至少保留当前与上一份），降低长文章的内存占用。后台保存仍需真机验证系统回收时序。
- 撤销/重做覆盖文本输入、格式、模块插入/删除/排序和图片替换；不能只调用浏览器默认 undo 后宣称全部支持。
- HTML 导入经过安全清理和兼容性转换；未知标签/样式尽量保留为原始 HTML 块。
- WebView 不开放任意文件访问和任意导航；桥接接口仅暴露最小必要方法，不能向不可信网页开放 JS bridge。
- 长文采用变更增量和防抖序列化，避免每次按键都触发完整 Compose 重组或大对象写盘。

## 12. 开发阶段与交付门槛

### 阶段 A：数据底座与文章管理
数据模型、旧备份兼容、样式分类 ID、文章列表、新建/打开/复制/删除、自动保存、版本快照、素材资源目录。完成后必须通过旧 JSON 导入/导出回归。

### 阶段 B：编辑内核与基础排版
独立 WebView、光标/选区保存恢复、撤销重做、文字格式、段落、列表、链接、表格、粘贴清理、HTML 导入导出。每项均有实际交互测试。

### 阶段 C：秀米式模块与样式中心
模块选择、插入位置、拖动排序、复制/删除/替换、内置组件库、我的样式、整篇模板和局部模板。

### 阶段 D：媒体与公众号适配
图片多选、持久化、裁剪/替换/图组、图注、媒体卡片、移动端阅读预览、公众号兼容性检查、富文本复制。

### 阶段 E：质量与发布
长文性能、异常退出恢复、历史版本恢复、导入导出往返测试、全量工具栏回归、APK artifact 核验和设备交互验收。

每阶段先完成可用闭环，再进入下一阶段；不能把「按钮已显示」或「Gradle 编译通过」当作功能完成。无法真实支持的公众号平台能力必须标明限制。
