# 拾万句 APP 功能

- **排版制作**
  - 公众号账号选择与切换
  - 版式选择、文案分类与数量设置
  - 文案随机读取、配图随机读取
  - emoji、动图、往期内容的默认插入、手动选择与移除
  - 抖音版式及背景图随机选择
  - 实时排版预览与内容复制

- **编辑模式**
  - 随机标题窗口与标题切换、复制
  - 编辑设置窗口
  - 悬浮窗拖动、缩放与层级切换
  - 往期和动图边距调整
  - 预览内容空行调整
  - 复制当前预览内容

- **我的**
  - 公众号账号管理
  - 文案模块管理
  - 版式管理
  - 配图、emoji、动图和往期内容管理
  - 配置新增、编辑与删除

- **数据备份**
  - 全部配置导出为 JSON
  - 从 JSON 备份文件导入恢复
  - 本地保存账号、文案、版式及素材配置
