# 拾万句 APP 图标视觉重设计方案

## 版本与保留规则

- 历史版本：v1（截至 APP 1.0.60 的 11 款图标）。
- 历史生成脚本：`native-overlay/icon-history/v1_1.0.60/generate_icon_styles_v1.py`。
- 历史版本不覆盖、不删除；后续新图标独立放在 v2 资源目录，验证通过后才切换应用引用。
- Logo 必须继续使用仓库权威 SVG 中原有的三个路径，不描摹、不重画、不拉伸、不裁切。

## 总体设计原则

1. **先做材质，再做装饰**：每种风格先确定真实材料、光线、工艺和边缘细节，避免给同一张底图套滤镜。
2. **拒绝 AI 套路**：不使用无意义的霓虹光晕、塑料渐变、随机星点、泛滥的 3D 高光、无逻辑装饰和过度对称的生成式纹理。
3. **图标要像设计师做出来的成品**：明确主次、留白、网格、边缘、印刷/缝制/绘制工艺；细节只为主题服务。
4. **Logo 是统一识别核心**：11 款使用完全相同的 Logo 路径、轮廓比例和视觉占比；只改变承载 Logo 的材质环境与配色。目标视觉占比回到约 66%，并以实机桌面与文件夹截图复核。
5. **缩小后仍可识别**：先按桌面图标实际尺寸检查，再看大图细节；不能依赖小尺寸看不见的纹理。
6. **不是 11 张同模板换皮**：各款应有各自独立的构图语言和工艺特征，但统一图标画布、Logo 基准和边距。

## 11 款重新构思

| 名称 | 必须一眼识别的视觉语言 | 具体工艺与细节 | 明确禁止 |
|---|---|---|---|
| 原版 | 品牌基准、克制、温润 | 保留品牌原有暖色气质；哑光底、细腻纸感或陶质触感，干净留白 | 复杂装饰、抢 Logo 的纹理 |
| 牛仔 | 真正的牛仔布与工装细节 | 靛蓝斜纹布、清晰经纬斜纹、双排浅色车线、局部磨白、黄铜铆钉或皮牌；像一枚缝在牛仔夹克上的布章 | 蓝色渐变、卡通牛仔帽、随意贴纸 |
| 代码 | 精密、理性、工程感 | 深石墨底、等距像素网格、少量语法色、终端光标/括号/代码行的秩序化排版；像真实开发工具图标 | 荧光绿泛光、满屏乱码、赛博朋克光污染 |
| 简笔画 | 一笔成形、手绘线条 | 米白纸底、深色墨线、线宽有轻微变化、少量笔触起收和不完美弧线；极简但有手感 | 完美机械描边、复杂底纹、卡通贴图 |
| 毛绒 | 像真的毛绒玩具，不是粉色塑料 | 短绒/羊羔绒纤维可见，绒毛沿边缘形成细小毛边；Logo 以刺绣布贴或软填充绣线呈现；有缝合线、轻微压痕和柔软厚度 | 平滑渐变、塑料高光、仅加几根白线假装毛茸茸 |
| 天空 | 清透、轻盈、真实天空意象 | 采用有限色块的晴空蓝与云白；云形像纸雕/丝网印刷剪影，边缘清爽；可有克制的太阳圆片 | AI 云雾、彩虹渐变、梦幻光斑 |
| 深空 | 天文图谱，而非普通星空壁纸 | 深蓝黑底、精确轨道弧线、星图坐标、少量印刷网点和金属墨点；像老式天文观测图或航天任务徽章 | 随机星星散落、紫色宇宙渐变、廉价科幻光效 |
| 涂鸦 | 街头喷漆和手写标记 | 混凝土/粗纸底、喷漆颗粒与边缘飞散、模板遮喷、马克笔笔触；颜色控制在 2–3 个主色 | 随机涂鸦符号、彩虹爆炸、无层次的贴纸拼贴 |
| 童趣 | 有趣但不幼稚，像精心制作的玩具 | 采用木质积木、彩色纸片或搪胶玩具的形体语言；形状简洁、色彩明快、比例有趣；细节有实体工艺逻辑 | 婴幼儿卡通脸、随机表情、廉价 3D 糖果质感 |
| 8-Bit | 真正的像素艺术 | 统一像素网格（建议 8px 基础单位）、硬边像素、有限调色板、局部有目的的抖动渐变；每个像素边缘清晰，不做抗锯齿 | 模糊像素、圆滑矢量渐变、像素字体之外的随机马赛克 |
| 手稿 | 铅笔/炭笔设计草图 | 有纸张纤维、石墨颗粒、辅助构图线、擦除痕迹、线条轻重变化；像设计师在素描本上完成的图稿 | 均匀噪点滤镜、做旧污渍堆砌、仿旧边框 |

## 统一制作规格

- 画布：正方形，所有资源统一基准尺寸，输出高分辨率母版和 Android 各密度资源。
- Logo：使用原始三路径；同一缩放比例、同一中心基准；目标可视宽度约为画布 66%。不允许不同风格各自估算大小。
- 细节：以缩小后的可读性为准，禁止用高频纹理填满整个图标。
- 图标底图：风格纹理必须在高分辨率母版中完成；避免运行时前景/背景分别缩放造成占比漂移。
- 预览：先输出 11 款统一尺寸的并排总览，再输出每款 1:1 细节图；并排图必须能区分风格而不显杂乱。
- 验收：静态资源检查 + APK 资源检查 + 实机桌面/文件夹/应用内选择页三处截图比对。系统 Launcher 可能对图标做遮罩和缩放，不能仅凭 PNG 尺寸宣称实机显示一致。

## 实施顺序

1. 先完成 11 款材质与构图草案，不改当前应用资源引用。
2. 生成新旧对照总览，逐款检查名称与质感是否匹配。
3. 对毛绒、8-Bit、牛仔、手稿四款重点做材质验收，作为风格差异的标杆。
4. 全部通过后将新资源放入独立 v2 目录，并接入独立资源命名；旧 v1 永久保留。
5. 构建 APK，检查图标切换、桌面、文件夹和选择页，不通过则回滚到 v1。
