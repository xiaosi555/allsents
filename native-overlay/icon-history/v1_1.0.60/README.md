# v1 历史图标留档

此目录保存拾万句 APP 1.0.60 之前的 11 款图标生成脚本。它用于复现旧版图标，不再作为 v2 的设计基准。

- 旧版生成脚本：`generate_icon_styles_v1.py`
- 对应旧版实际 PNG：由 1.0.60 原生工程构建产物中的 `res/drawable-nodpi/icon_style_*.png` 提取。
- v2 设计要求：见仓库 `native-overlay/icon-history/ICON_REDESIGN_V2_BRIEF.md`。
- 规则：v1 永久保留；v2 使用独立资源名和目录；未经对照验收不得覆盖 v1 或切换 APK 默认图标。

当前 v1 的 11 张实际 PNG 已另行打包为 `拾万句_图标历史版本_v1_1.0.60.zip`，包含 original、cowboy、code、line、plush、sky、space、graffiti、playful、8bit、sketch。
